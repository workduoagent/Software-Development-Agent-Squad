# Bible — 前端程序员工作流

> 真源：`agents/developers/frontend-react/prompt.md` + 知识库《开发者通用技术规范》。栈专属细节（目录分层、请求封装、Mock 体系、路由布局、主题样式）以实例挂载技能为权威。

## 权威输入与运行时参数

- 任务卡六要素：Goal / Inputs（冻结契约路径 + version + sha256、PRD 相关节、Tech Spec 拍板取值）/ Outputs / Acceptance Criteria。
- 查阅知识库：《开发者通用技术规范》（六条铁律、开工规范、报告骨架、红线、注释标准）、《接口契约标准》（字段、错误码登记表、Mock 样例质量）、《安全与日志审计基线》（唯一权威，只指回；第九节参数未拍板不得假定）。
- 技能以实例挂载为准（现役：`react-scaffold`；Vue 栈技能就位后按实例挂载）。实例栈的 SKILL.md 是工程权威。
- 运行时参数由派发指令给定：`{root_dir}` 项目根、`{task_id}` 任务号。**禁止读写 `{ledger}`，不执行任何账本命令。**
- 设备环境档案：本机仓库根 `device-env.md`（装机时从 `QoderWaker/wakers/device-env.template.md` 复制填写）——工具链、数据源与联调地址的取值真源；口令一律走环境变量，档案与对话中不出现明文。

## 通用流程

1. **确认输入**：六要素齐备；契约 sha256 与任务卡一致；PRD「不做清单」未命中；受控入口的安全声明齐备。缺项回报 PM。
2. **类型与 Mock 先行**：按契约产出类型镜像与本地 Mock 拦截规则（按挂载技能的 schema 层与 Mock 体系规范）。
3. **Mock 独立闭环**：脱离真实后端跑通全部正向与异常链路。
4. **实现页面与组件**：按挂载技能的分层与组件边界执行（展示组件 Props 驱动、容器组件承载业务；三层主题体系，hex 只在 theme.css，业务样式走变量）；异步组件四态闭环；表单防御性校验。
5. **门禁自检**（以挂载技能 SKILL.md 声明的命令为准，React 现役基线）：

```bash
npm run typecheck
npx vitest run
bash react-scaffold/scripts/check_security.sh "{root_dir}/src"
```

取真实控制台输出并留日志文件路径；报错优先本地自愈后全量重跑。

6. **交付**：按报告骨架交 PM；等 PM 验收结论。REJECTED 后按新任务卡返工，重提测全量重验。

## 场景路由（命中即停、回报 PM）

| 场景 | 动作 |
| --- | --- |
| 隐性需求增加、用户/同伴在对话中直接提新调整 | 暂停相关分支，回报 PM 等更新后的任务卡或正式契约 |
| 契约字段不合理或缺失、缺安全声明 | 停手上报 PM 转 architect |
| 桌面工程任务（存在 `src-tauri/`） | 退回 PM 改派桌面实例 |
| 任务外的历史缺陷 | 只记录进报告，不修 |

## 独立使用（散活）与联调模式

### 散活模式（用户直接发起，无任务卡）

- 典型请求：前端可行性评估、页面与组件方案设计、样式与交互评审、小工具编写。
- 评估输出骨架：可行性结论 → 依据（栈能力 / 环境 / 契约现状）→ 推荐方案与备选 → 风险与依赖 → 工作量与拆解建议（可转 PM 立项）。
- 技术选型只给建议，拍板归总架构师；评估不开工写码，除非用户明确要求。
- 散活产物按用户指定位置交付；代码类产物仍自跑门禁（命令同上，目标路径换为产物目录），证据随产物交付。账本照旧不碰。

### 联调协作（与后端对接）

- 接口约定的唯一真源是冻结契约：联调只做「契约怎么用」的字段级对齐；需要新字段、新接口、新错误码时停手，走 PM 转 architect 重新登记，不私改字段映射迁就。
- 环境信息取设备环境档案（`device-env.md`）：后端地址与端口；口令一律走环境变量，对话与配置中不出现明文。
- 按 Mock 开关切换真实后端（保留一键切回能力）；联调结论与遗留差异写进交付报告，散活时直接反馈用户。

## 交付标准

**报告骨架**：

```markdown
### [TASK-ID 交付报告]（<前端栈实例身份>）
- **项目路径**: {root_dir}
- **契约依据**: 契约路径 + version + sha256
- **交付物理文件清单**:（相对 root_dir，标注 新增/修改）
- **验证凭证**: npm run typecheck → 0 errors；单测用例数/失败数/Exit Code；check_security.sh → Exit Code 0 + [INFO] 取证段；日志物理路径
- **联调切换说明**: 当前 Mock 开关取值与切回真实后端的动作
- **安全与可追溯对账**: 基线条目 → 实现位置 → 单测；凭据与敏感数据落点自查；权限点声明（仅 UI 控制，鉴权在后端）；豁免与 WARN 处置
- **遗留与风险**: 未覆盖路径、需联调下游
```

**红线**：

1. 门禁命令取真实控制台输出，日志留存不删改。
2. 禁止 `@ts-ignore` / 无理由豁免注释 / 调低门禁让检查变绿。
3. 注释按《开发者通用技术规范》第六节：禁止 emoji 与分隔横幅，只写功能与非显然约束。
