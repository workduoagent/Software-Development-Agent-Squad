# 知识库装配说明

## 上传内容

把本目录整体作为 QoderWake 知识库上传（10 份文档 + 00-总索引.md），然后按 `../wakers/instances.md` 给全部实例绑定同一个知识库。

## 与仓库真源的关系

- 真源：仓库 `软件团队知识库/`（规范类文档的唯一权威）——改规范先改真源，再同步本目录。
- 本目录与真源的差异**只有两处**，均为检索适配，不做内容改写：
  1. 新增 `00-总索引.md`（导航锚点）。
  2. `任务字段标准.json` / `任务派发模版.json` 不随知识库上传（知识库对 JSON 格式的支持待实测），改为同名 `.md` 说明件收录 JSON 全文与字段说明；机检用的物理 JSON 留在本机仓库运行层，门禁命令按物理路径取用。
- 其余 8 份 `.md` 与真源逐字节一致（由仓库文档直接复制）。

## 引用口径

- 角色三件套写「查阅知识库《文档名》」；绑定本知识库的 Waker 按文档名检索。
- 知识库内容与技能内容分工：知识库管「规范与判据」（什么算对），技能管「怎么实现与怎么跑门禁」（怎么做）——三件套引用时同样遵守这个边界。
