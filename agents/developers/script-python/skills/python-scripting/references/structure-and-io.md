# 形态选择与 IO 纪律

## 形态选择

- **单文件**（默认）：≤300 行、单入口、依赖 ≤5 个。
- **小型工程**：多入口或 >300 行——

```
<project>/
├── script/           # 入口（每个入口一个文件，main() + argparse/click）
├── lib/              # 可复用函数模块（纯函数优先，方便测试）
├── tests/            # 纯函数单测（pytest）
├── requirements.txt  # 精确版本 + 用途注释
└── README.md         # 运行说明：一条命令可重跑
```

## IO 纪律

- **读**：先探测存在性与规模；大文件流式处理（逐行/分块），不一次性读入内存。
- **写**：输出目录必须显式传入（`--output`）；覆盖需 `--overwrite` 或用户事先声明可覆盖。
- **中间产物**：进 `--tmp-dir` 指定目录或 tempfile；用完即删，不留在输出目录。
- **编码**：文件读写一律显式 `encoding="utf-8"`；CSV/JSON 读入注意 BOM 与换行差异。
- **异常**：捕获后记日志再决定重试或退出；禁止裸 `except: pass`；兜底异常也要给非零退出码。
- **日志**：logging 双通道（文件 + 控制台）；关键步骤、处理行数、跳过原因留痕；日志文件随输出目录走，命名含时间戳。
