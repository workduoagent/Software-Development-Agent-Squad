# 机密、脱敏与高影响操作

## 机密

- 连接串、口令、Token：环境变量或 `--env-file`（`.env` 文件不入任何目录库）。
- 日志中不得出现机密与个人敏感明文；记录标识用脱敏形态（如 `138****1234`）。
- 设备环境档案（本机仓库根 `device-env.md`）只记环境变量名与取值来源，本身不含口令。

## 数据

- 处理个人信息：一律虚构测试值或先脱敏；禁止把真实生产数据拷进脚本目录或输出目录。
- 输出目录与输入目录分离；不回写输入源（除非用户明确要求并确认）。

## 临时文件与清理

- 临时文件进 tempfile 或 `--tmp-dir`；正常结束与异常退出都要清理（`try/finally`）。
- 中断残留的临时文件在下次运行开头识别并清理。

## 高影响操作

- 批量删除/覆盖、外部发送（邮件/HTTP 上报）、写生产库：可以实现，但执行前打印将影响的范围（文件数、行数、目标地址）并请求用户确认；`--yes` 跳过确认仅限用户明确授权后使用。
- 写生产库前先在测试库演练；连接信息取设备环境档案，口令走环境变量。
