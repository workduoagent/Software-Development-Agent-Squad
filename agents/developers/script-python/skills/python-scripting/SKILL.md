# Python 脚本工程通用 Skill

## Overview

为脚本形态（非长期服务）建立的初版基线：**一条命令可复现、可重跑、无机密**。
与 `python-backend-scaffold` 的分界：本 skill 不提供常驻服务与路由层；需求需要服务化（路由、鉴权、业务库）时，转后端程序员评估，不硬塞脚本形态。

## 技术栈基线

**Python 3.12** · 标准库优先 · click（CLI 参数）· logging · requests / httpx（按需）· pandas（按需，数据处理）

## 核心纪律（不可违背）

1. **入口唯一**：`main()` + `if __name__ == "__main__"`；可复用逻辑函数化。
2. **参数显式**：argparse/click 声明全部参数；禁止硬编码路径、URL、口令。
3. **路径跨平台**：pathlib；输出写显式指定目录，不散落当前目录。
4. **编码显式**：文件读写一律 `encoding="utf-8"`。
5. **日志而非 print**：logging 落文件 + 控制台；关键步骤与处理行数留痕。
6. **幂等可重跑**：同输入重复执行结果一致；输出可安全覆盖或按内容去重。
7. **机密不入码**：连接信息走环境变量或 `--env-file`；代码与日志无明文。
8. **退出码语义**：0 成功、2 参数或输入错误、1 运行失败；异常不被静默吞掉。
9. **依赖钉版本**：脚本自带 requirements.txt；不装不用的包，不动全局环境。
10. **敏感数据**：个人信息一律虚构测试值或先脱敏；临时文件用完即删。
11. **高影响操作先确认**：批量删除/覆盖、外部发送、写生产数据——实现但执行前打印将影响的范围并请求用户确认。
